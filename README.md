# ⚡ 報寶貝 · 全台灣火箭隊即時情報雷達 (Team GO Rocket Radar)

專為 Pokémon GO 玩家打造的報寶貝 (`https://twpkinfo.com/igym.aspx`) 火箭隊佔領補給站專屬情報系統，支援**全台灣全島 9,600+ 處補給站即時掃描**與**第一隻角色確定性精準篩選**。

---

## 🌟 核心功能特色

### 1. 🇹🇼 全台灣全島即時掃描
- 突破傳統分區限制，**1~2 秒內即可同步全台灣 9,600+ 處**正在被火箭隊佔領的補給站！
- 同時支援分區快速切換（全台灣、大台北、新北基隆、桃園、新竹、台中、彰化南投、雲林嘉義、台南、高雄、屏東、宜蘭、花蓮、台東）。

### 2. 🎯 第一隻對手角色「確定性分級」與「省時快篩」
針對玩家最關心的「能不能確定第一隻出什麼以節省時間」，系統提供三大確定性分級與一鍵過濾：
- 🟢 **【100% 確定】（首發完全固定，不用猜直接打）**：
  - **三大幹部 (亞洛、克里夫、希爾拉)**：當季第 1 隻角色全台統一固定，必出且能遭遇異色 ✨！
  - **最高首領 阪木老大**：100% 必定首發貓老大。
  - **無屬性男小兵 (台詞「贏的機率很小/不知道嗎」)**：100% 必定首發**卡比獸**！
  - 網頁介面提供 **「🎯 100% 確定首發」** 按鈕，一鍵秒出全台數百隻卡比獸與幹部！
- 🟡 **【高機率限定 (2選1)】（高價值必打神怪）**：
  - **龍屬性女小兵**：高達 85% 機率出**迷你龍**或**寶貝龍**（不論出哪隻都是頂級暗影龍，必刷！）。
  - **鋼屬性男小兵**：極高機率出**鐵啞鈴**（暗影巨金怪必備）。
  - **格鬥女小兵**：高機率出**猴怪**（棄世猴熱門）或**腕力**。
  - **妖精女小兵**：高機率出**拉魯拉絲**（暗影沙奈朵）。
- ⚪ **【多選輪替】**：
  - 水系、火系、草系等，附上該屬性出場機率最高的前兩名角色與陣容池。

### 3. 🏷️ 屬性分類與男女小兵標註
- 18 種屬性獨立標籤與即時數量統計（點擊標籤立刻過濾全島該屬性所有點位）。
- 清楚標註【男小兵 ♂】、【女小兵 ♀】、【👑 幹部】與【☠️ 老大】。

### 4. ⏳ 即時倒數與一鍵導航
- 即時計算各補給站剩餘時間（低於 5 分鐘紅色脈動預警）。
- 一鍵複製經緯度座標。
- 一鍵開啟 Google Maps 路線規劃。

## 🚀 快速啟動

### 1. 安裝必要套件
```bash
pip install -r requirements.txt
```

### 2. 啟動 Web 介面 (推薦)
```bash
python app.py
```
打開瀏覽器訪問：👉 **`http://127.0.0.1:5050`**

### 3. 命令列 CLI 模式
```bash
python rocket_crawler.py
```
終端機會直接印出全台灣 9,600+ 處火箭隊的屬性排行、第一隻出場確定性與詳細清單！
